# Fonts

The portfolio self-hosts Space Mono and Spectral. Both families are distributed under the SIL Open Font License 1.1; their complete copyright and license notices are included alongside the fonts.

| File | Family | Style | Weight |
| --- | --- | --- | --- |
| `font-0.ttf` | Space Mono | Regular | 400 |
| `font-1.ttf` | Space Mono | Bold | 700 |
| `font-2.ttf` | Spectral | Light Italic | 300 |
| `font-3.ttf` | Spectral | Light | 300 |
| `font-4.ttf` | Spectral | Regular | 400 |

`fonts.css` maps these files to the families and weights used by the site. The font binaries retain their original copyright metadata.
